# Synthetic test data

Generated by `python -I scripts/make_synthetic.py` (seeded, so reruns are byte-identical). `large_*.csv` are
git-ignored; run the script to create them.

Every file has a `row_id`. **In Tableau, put `row_id` on Detail** so there is one mark per record. Without it
Tableau aggregates to one row per category and there's no distribution to draw.

| File | Rows | Columns | Tests |
|---|---|---|---|
| `quirks.csv` | 373 | category, value, segment, region | The gallery groups: uniform, gap at median, whole numbers; outliers in A and C |
| `skewed_delivery_minutes.csv` | 1,200 | courier, delivery_minutes, … | Right-skewed (lognormal): long tails, histogram vs density, truncation |
| `outliers_response_ms.csv` | 1,500 | server, response_ms, … | ~1% extreme outliers (8–25×): P1–P99 truncation |
| `likert_satisfaction.csv` | 600 | department, score (1–5), … | Heavy ties: histogram cloud, dot stacking; one polarised department |
| `small_n.csv` | 107 | category, value, … | n = 1, 3, 8, 15, 60, plus a zero-variance group (all 42) |
| `many_categories.csv` | 2,239 | store, value, … | 24 categories: layout, labels, colour |
| `edge_cases.csv` | 240 | category, value, … | Negatives, mostly zeros, nulls in value, an all-null group, a null category |
| `repeated_measures.csv` | 120 | participant, group, time, score | 40 people × Pre/Post/Follow-up: linking lines later |
| `large_10k.csv` / `large_100k.csv` | 10k / 100k | category, value, … | Performance: Normal, Skewed, Bimodal, Uniform |

`segment` (Alpha/Beta) and `region` (N/S/E/W) are random, for colour, split and filter tests.
