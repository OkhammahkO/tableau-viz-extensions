# Raincloud 1.1.1

A small fix release.

- **Selections survive filters.** Before, if you selected dots and then filtered the sheet, the extension could
  highlight different records from the ones Tableau kept selected. It now remembers the records themselves.

Nothing to do: workbooks using the public `raincloud.trex` get the fix automatically. The website also has a new home
page for both extensions: https://okhammahko.github.io/tableau-viz-extensions/ (the raincloud's page moved to
[/raincloud/](https://okhammahko.github.io/tableau-viz-extensions/raincloud/)).
